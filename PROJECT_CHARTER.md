# Project Charter

## Project Title
Post-purchase CX Redesign for Marketplace Delivery Failures

## One-sentence Summary
This project uses the Olist marketplace dataset to diagnose post-purchase delivery failures and translate the findings into a service recovery design for marketplace operators.

## Business Problem
Marketplace platforms often treat late delivery as a logistics issue, but for customers it becomes a trust, communication, and service recovery problem.

## Stakeholders
- Head of Customer Experience
- Marketplace Operations
- Seller Governance
- Logistics Operations
- Product / Service Design Team

## Core Research Questions
1. Where do post-purchase delivery failures occur?
2. How is late delivery associated with review score?
3. Which sellers, categories, and regions create the highest risk?
4. What pain points appear in low-score review text?
5. Where should the platform intervene before users leave bad reviews?
6. What service recovery system should be proposed?

## Final Outputs
- GitHub repo
- Case study report
- PowerPoint deck
- Dashboard
- Journey map
- Service blueprint
- Pain point taxonomy
- Service recovery concept
- KPI and validation plan
- China localization memo

## Scope
This project focuses on post-purchase marketplace experience, especially delivery promise failure, customer dissatisfaction, seller risk, and service recovery.

## Limitations
The Olist dataset is historical and observational. It can show association, not causality. It does not include internal customer support tickets, compensation records, notification logs, or actual platform recovery actions.
