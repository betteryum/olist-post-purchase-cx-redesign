# AI Context for Olist Post-Purchase CX Redesign

## Project Positioning

This project is not a generic Olist EDA project.

It uses the Olist Brazilian E-Commerce dataset to diagnose post-purchase customer experience failures, especially late delivery, review dissatisfaction, and uneven seller/category/region risk.

The final goal is to translate data findings into a service recovery system for marketplace platforms.

## Core Logic

delivery failure
→ review impact
→ seller/category/region risk
→ review pain points
→ journey map
→ service blueprint
→ recovery concept
→ KPI validation plan

## Evidence Levels

Level 1: Direct data analysis

Level 3: Proposed intervention and validation
- service recovery concept
- seller governance logic

- future pilot / A/B test plan

## Important Claim Discipline

Allowed wording:
- Olist data shows late delivery is associated with lower review scores.
- Seller, category, and region risks are unevenly distributed.
- Review comments can be coded into post-purchase pain point categories.
- Journey map and service blueprint are data-informed syntheses.
- The recovery system is a proposed intervention that needs future validation.

Avoid wording:
- Olist data proves the recovery system will work.
- Olist data reveals Olist's real internal service blueprint.
- Late delivery fully causes low reviews.
- Retention is the strongest business impact finding.
